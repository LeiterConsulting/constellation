# Terms used in Constellation

| Term | Meaning here |
| --- | --- |
| Canvas | The area showing the current dashboard preview. |
| Tile / visualization | A chart, table, value or other native visual element. |
| Draft | Your private working dashboard, conversation and context in Constellation. |
| Brief | Purpose, audience, requirements, units and exclusions kept with the draft. |
| Focus | The chart, input or page targeted by the next conversational request. |
| Data scope | The selected index/search, language, time range and relevant report context. |
| Field inspection | A bounded sample used to describe fields and coverage; not a complete schema or population count. |
| Input / token | A dashboard control and the value used to filter or navigate the dashboard. |
| Snapshot | A retained preview result. It can be complete, partial, waiting, failed or stale. |
| Native copy | A normal private Dashboard Studio dashboard created by Save to Splunk. |
| Portable file | Exported dashboard JSON with explicitly included supported artwork/dependencies. It can contain sensitive data. |
| Connection test | A small provider/model structured-response check; not full dashboard qualification. |
