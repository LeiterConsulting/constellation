# Sharing the 1.0 release

Use the [release downloads](https://github.com/LeiterConsulting/constellation/releases/tag/v1.0.0), verify SHA256SUMS and follow the [installation guide](installation.md). The documentation bundle includes the same qualified app plus the current guides and screenshots.

First-party code and documentation use the [MIT License](../LICENSE). Keep the license with redistributed copies and preserve third-party notices. The repository remains private; access to its downloads and public repository visibility are separate owner decisions.

## Before a recipient starts

1. Check the [supported deployment profile](support-policy.md).
2. Have an administrator configure network/provider access, and shared AITK when needed.
3. Verify the intended ordinary author's create/edit/save/reopen path.
4. Review [data handling](../SECURITY.md), particularly provider context, private draft attachments, shared artwork and CSV portability.
5. Provide the [user guide](user-guide.md) and [troubleshooting](troubleshooting.md).

A readable native dashboard still needs data/report/lookup/asset access for its viewers. A private draft link is owner-restricted; it is not a sharing token.

The [release evidence](validation.md) records bounded technical qualification. The older [0.9 sharing review](history/sharing-review.md) remains historical evidence, with its original status and limits.
